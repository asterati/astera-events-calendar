# Astera Events Calendar

Calendário institucional da Astera. App em React com uma grade/lista de eventos agrupados por mês, cada evento com data, horário, nome, uma cor por tipo de iniciativa, e um botão ‘Entrar na aula’ quando houver link de reunião. Visual limpo, legível, com legenda de cores por tipo no topo. Sem backend por enquanto — os dados vêm de um arquivo data.json
